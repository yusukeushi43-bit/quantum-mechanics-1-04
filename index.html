考察

測定回数による分布の変化を説明し、10,000回で表示される理論曲線と比較する。

「ばらつき」と「推定の精度」

測定回数を増やすと、分布の形や広がりの推定は安定していきます。でも、同じ状態の粒子がもつ分布そのものの広がり Δx・Δpₓ は変わりません。

有限回の測定には、揺らぎがある

表示する s は標本標準偏差です。少数のデータでは理論値から外れます。別々の標本から求めた sₓsₚ が一時的に ℏ/2 を下回っても、不確定性原理の反例にはなりません。

教員用：解説・つまずきやすい点

3条件の答え（C = 0）

Δx が 0.50 → 1.00 → 2.00 のとき、Δpₓ は 1.00 → 0.50 → 0.25。積はすべて 0.50 ℏ。p₀ を動かしても Δpₓ は変わりません。

誤解を避ける言い方

ここでの不確定性関係は、同じ量子状態について位置と運動量の分布がどれだけ広がるかという制約です。測定器の誤差や「測定で粒子を乱した量」そのものを表す式ではありません。

このシミュレーションの限界

1次元のガウス波束というモデルの予測を体験します。自然界での実験的検証そのものではありません。あらゆる状態をこの操作で作れるわけではなく、一般的な証明には演算子の数学が必要です。

スリット実験を使う場合

「狭いスリットほど回折が広がる」は導入に役立ちます。ただし理想的な矩形スリットの sinc² 分布は、運動量の分散が発散します。回折の中央ピーク幅をそのまま Δpₓ と呼ばないようにします。

モデル・数式・参考資料 ＋

この実験室が計算しているもの

位置の中心 x₀ = 0 の1次元ガウス波束を扱います。q = x/L、k = pₓL/ℏ とし、画面上の σ = Δx/L、μ = p₀L/ℏ は無次元の数値です。

ψ(q) = (2πσ²)−1/4 exp[−(1 − iC)q² / (4σ²) + iμq]

位置の確率密度は平均 0・標準偏差 σ の正規分布、運動量の確率密度は平均 μ・標準偏差 √(1 + C²)/(2σ) の正規分布になります。このため ΔxΔpₓ/ℏ = √(1 + C²)/2 ≥ 1/2。C = 0 のときに最小値をとります。グラフは波動関数そのものではなく、その絶対値の2乗（確率密度）です。

仮想測定はこの確率分布から独立に乱数を生成しています。グラフは有限の範囲を表示しますが、分布は無限に続きます。標本標準偏差は分母 n − 1 で計算し、範囲外の測定値も含めます。
