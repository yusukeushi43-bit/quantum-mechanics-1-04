実験 02

位置と運動量の測定

何を、どう測る？

  1. 1
    同じ状態を用意する

    位置の広がり Δx を決めます。測定するたびに、同じ状態の新しい粒子を用意します。

  2. 2
    1個ずつ値を読み取る

    一方の集団では位置、別の集団では運動量を測ります。「10回」なら、それぞれ10個の値が得られます。

  3. 3
    結果を棒グラフにする

    似た値をまとめ、出やすさを表示します。回数を増やして形を確かめ、各10,000回で理論曲線と比べます。

実際の測定との対応

位置は、検出器上の「どこで検出されたか」から読み取れます。運動量は、例えば自由に飛ばした粒子の飛行時間と移動距離から推定します（初期位置の広がりや装置の分解能も考慮します）。ここでは装置を理想化し、量子状態の確率分布に従って測定値を生成しています。

同じ1個の粒子の位置と運動量を、同時に正確に測る操作ではありません。

考察

まず標準の状態で測り、「この測定結果を残す」を押す。次に Δx を狭くして同じ回数測り、運動量の山の幅と高さを比べる。

「ばらつき」と「推定の精度」

測定回数を増やすと、分布の形や広がりの推定は安定していきます。でも、同じ状態の粒子がもつ分布そのものの広がり Δx・Δpₓ は変わりません。

有限回の測定には、揺らぎがある

表示する s は標本標準偏差です。少数のデータでは理論値から外れます。別々の標本から求めた sₓsₚ が一時的に ℏ/2 を下回っても、不確定性原理の反例にはなりません。

解説

01：2倍。C = 0 では ΔxΔpₓ = ℏ/2。片方を半分にすると、もう片方は2倍になります。

02：広がりは変わりません。測定回数を増やすと分布の推定は安定しますが、量子状態そのものの広がりは変わりません。

03：山は低くなり、面積は一定。全確率が1なので、正規分布は横に広がるほど縦に低くなります。

モデル・数式・参考資料 ＋

この実験室が計算しているもの

位置の中心 x₀ = 0 の1次元ガウス波束を扱います。q = x/L、k = pₓL/ℏ とし、画面上の σ = Δx/L、μ = p₀L/ℏ は無次元の数値です。

ψ(q) = (2πσ²)−1/4 exp[−(1 − iC)q² / (4σ²) + iμq]

位置の確率密度は平均 0・標準偏差 σ の正規分布、運動量の確率密度は平均 μ・標準偏差 √(1 + C²)/(2σ) の正規分布になります。このため ΔxΔpₓ/ℏ = √(1 + C²)/2 ≥ 1/2。C = 0 のときに最小値をとります。グラフは波動関数そのものではなく、その絶対値の2乗（確率密度）です。

仮想測定はこの確率分布から独立に乱数を生成しています。グラフは有限の範囲を表示しますが、分布は無限に続きます。標本標準偏差は分母 n − 1 で計算し、範囲外の測定値も含めます。
